# InOffice Flow

این بسته بر پایهٔ `CFC-Flow-v1.1.0` آماده شده است.

## تغییرات این نسخه

- فایل‌های عملکردی اصلی بدون تغییر باینری حفظ شده‌اند: `app.js`، `engine.js`، `link.js`، `panel.js` و `stat.js`.
- popup با استایل، رنگ‌ها و لوگوی InOffice بازطراحی شده است.
- متن معرفی فارسی و سه لینک سایت، اینستاگرام و تلگرام در popup قرار گرفته‌اند.
- نام و توضیح نمایشی افزونه در `manifest.json` به InOffice تغییر کرده است؛ مجوزها، مقصدهای شبکه و مسیر اجرای کد اصلی حفظ شده‌اند.

## نصب محلی در Chrome

1. فایل ZIP را در یک پوشه استخراج کنید.
2. در Chrome به `chrome://extensions` بروید.
3. `Developer mode` را روشن کنید.
4. روی `Load unpacked` بزنید و پوشهٔ استخراج‌شده را انتخاب کنید.

بعد از نصب، popup افزونه را باز کنید، کلید را روشن کنید و تب Google Flow را دوباره بارگذاری کنید.

## نکتهٔ امنیتی

این بسته hardening عملکردی انجام نمی‌دهد تا رفتار نسخهٔ اصلی تغییر نکند. کد هستهٔ اصلی obfuscated است و `app.js` همچنان منطق و مقصدهای شبکهٔ نسخهٔ اصلی را دارد؛ بنابراین این بسته به‌معنای تأیید امنیت تولید یا تضمین موفقیت در هر حساب/شبکه نیست. قبل از نصب، مجوزها و فایل‌های بسته را بررسی کنید.
